02문제 발견

입력 후 오류 원인을 다시 찾는 업무

거래처 자료는 이메일·우편·카카오톡으로 내부 실무자에게 전달됐습니다. 실무자가 파일을 취합하고 엑셀로 정리해 입력하는 과정에서 자료 중복·누락과 잘못 전달된 자료를 확인해야 했습니다.

EDI 작업은 여러 메뉴에 흩어져 있었고, 입력값이 틀렸는지 원본 자료에 문제가 있는지 확인하려면 자료를 다시 대조해야 했습니다. 매출자료에서는 같은 제품코드 오류가 여러 업체에 반복됐습니다.

03판단과 설계

업무 흐름과 데이터의 성격에 따라 처리 방식을 나눴습니다.

살펴볼 판단 사례

오류별 통합 검증과 업로드 시점의 미매칭 확인 흐름 설계

기존
  1. 업체별 검증
  2. 같은 제품코드 오류를 업체마다 처리
설계
  1. 여러 업체 자료 임시 업로드
  2. 제품코드별 오류 모아 확인
  3. 일괄 매칭·재요청·중복 확인

확인 단위 변경: 업체별 → 오류별

같은 제품코드 오류가 여러 업체에서 반복됐습니다. 검증 단위를 업체로 유지하면 같은 확인을 반복하게 되므로, 현업 피드백을 반영해 오류 단위로 모아 판단하도록 바꿨습니다.

고객사 리뷰에서 업체별 화면 대신 여러 업체 자료를 함께 검토·처리하는 방향으로 정리됐습니다.

발견 시점 변경: 정산 시 → 업로드 시

기존에는 제품코드가 연결되지 않은 자료가 정산에서 빠지고, 이후 금액을 대조하면서 누락을 확인했습니다. 내부 실무자는 업체에 자료 보완을 요청하고 확인된 내역을 다음 달 이후 정산에 반영해야 했습니다.

업로드 시점에 제품이 연결되지 않는 항목을 표시해, 실무자가 보완 요청을 앞당길 수 있도록 설계했습니다. 다만 자료가 돌아오는 시점은 통제할 수 없으므로, 보완된 내역을 이후 정산에 반영하는 이월 방식은 유지했습니다.

후속 검증을 위한 제안 지표 · 미측정같은 오류의 업체별 반복 처리 건수, 미매칭 발견부터 보완 요청까지 걸린 시간, 다음 달 이후로 이월된 건수

오류 유형과 처리 기능 보기

사업자번호·매출일자 누락, 제품 매칭 실패를 유형별 건수로 표시하고 영향 업체와 오류 사유를 보여줬습니다. 일괄 매칭·자료 재요청·중복 확인으로 연결하고, 자료 보완이 필요하면 도매업체에 다시 요청하도록 했습니다.

구축 순서: 기존 마스터데이터 중심의 가정을 다시 검토했습니다.

처음 가정
  1. 기존 마스터데이터를 기준으로
  2. 들어오는 EDI 자료 분류
확인한 업무 구조
  1. 정산을 위해 받은 자료 분류·연결
  2. 마스터데이터와 EDI 자료 대조
  3. 거래 내역 계산·정산

처음에는 기존 마스터데이터를 기준으로 들어오는 EDI 자료를 분류하려 했습니다. 내부 실무자·TF 담당자와 업무를 확인하며, 정산을 위해 받은 자료를 마스터데이터로 분류·연결하고 EDI 자료와 함께 정산에 사용하는 구조를 파악했습니다.

마스터데이터 화면부터 만드는 대신, 정산에 필요한 자료의 분류·연결 흐름을 먼저 구체화해야 한다고 판단했습니다. 이를 바탕으로 정산 기능을 우선 구축하는 방안을 고객사에 제안하고 순서를 조정했습니다.

개발 우선순위정산 기능 → 마스터데이터 → 협력사 포털

후속 검증을 위한 제안 지표 · 미측정마스터데이터 구축 단계에서 생긴 구조 변경·재작업 건수, 계획 대비 정산 기능 일정

자료 검증 흐름과 개발 순서의 차이

EDI 수신 → 심평원 검증 → 마스터데이터 등록은 자료 처리 흐름입니다. 정산 기능을 먼저 구축했다는 것은 마스터데이터 없이 정산한다는 뜻이 아닙니다.

개발은 뒤로 조정하고, 작동 방식은 먼저 검토했습니다.

  1. 요청
    병의원 정보를 한 번에 조회

    취급 약품·배치된 CSO를 확인해 진입 가능 여부를 판단하려는 고객사 요청.

  2. 제약
    EDI·정산 기능이 먼저 필요

    정보를 연결하는 구조가 복잡해, 선행 기능 없이 바로 개발하기 어려웠습니다.

  3. 판단
    개발은 미루고, 화면 검토는 먼저

    선행 조건을 정리해 개발을 뒤로 조정하고, 고객사 제공 내용을 토대로 프로토타입을 제작했습니다.

  4. 산출물
    고객사와 검토한 프로토타입

    회의에서 작동 방식과 화면을 확인하고 피드백을 주고받으며 후속 개발을 준비했습니다.
