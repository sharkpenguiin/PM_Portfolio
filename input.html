01 · 발견한 문제

이메일, 우편, 카카오톡.
자료를 다시 모아 입력했습니다.

내부 실무자는 여러 경로로 받은 파일을 취합하고 엑셀로 정리해 입력했습니다. 이 과정에서 자료 중복·누락과 잘못 전달된 자료를 확인해야 했습니다.

02 · 역할 분리

거래처는 직접 올리고,
실무자는 대조하고 확정하도록.

자료 전달 경로를 포털로 모아 거래처가 직접 업로드·확인하도록 설계했습니다. 실무자는 취합·입력 대신 대조·보정·확정을 맡도록 역할을 나눴습니다.

03 · 검증 정책

직접 고르는 값은 제한하고,
외부에서 온 값은 확인했습니다.

직접 입력은 해당 거래처의 허용 품목을 먼저 보여 주고, 마스터에 없는 제품은 검색되지 않도록 제한했습니다. OCR·파일 업로드로 들어온 품목은 수신 후 허용 여부를 대조하도록 설계했습니다.

거래처와 실무자의 역할을 나누고, 경로별 검증 방식을 고객사 리뷰에서 합의했습니다.

  1. 01상황과 문제여러 경로로 온 자료를 실무자가 취합·입력했습니다.
  2. 02해결전달 경로를 포털로 모으고, 실무자는 대조를 맡도록 설계했습니다.
  3. 03결과고객사 리뷰에서 합의해 요구사항 명세에 반영했습니다.
01

상황과 문제

기존 업무여러 경로로 오던 거래처 자료

  • 거래처 자료는 이메일·우편·카카오톡으로 내부 실무자에게 전달됐습니다. 실무자가 파일을 취합하고 엑셀로 정리해 입력하는 과정에서 자료 중복·누락과 잘못 전달된 자료를 확인해야 했습니다.
  • 직접 선택하는 화면은 선택지를 미리 제한할 수 있지만, 외부 자료는 들어온 뒤에야 확인할 수 있습니다.
02

해결

자료 전달 경로를 포털로 모아 거래처가 직접 올리도록 하고, 실무자는 취합·입력 대신 대조·보정·확정을 맡도록 역할을 나눠 설계했습니다.
