웰던프로덕트ERP 기획2026.04–2026.06

EDI 입력 경로별 정책

직접 입력은 틀린 품목을 고를 수 없게, 외부 자료는 들어온 뒤 대조하도록 설계했습니다.

  • 본인 역할입력 경로별 검증 방식 설계
  • 기획 범위ERP·협력사 포털, 18개 업무 영역 단독 기획
  • 진행 상태명세 반영

거래처와 실무자의 역할을 나누고, 경로별 검증 방식을 고객사 리뷰에서 합의했습니다.

  1. 01상황과 문제여러 경로로 온 자료를 실무자가 취합·입력했습니다.
  2. 02해결전달 경로를 포털로 모으고, 실무자는 대조를 맡도록 설계했습니다.
  3. 03결과고객사 리뷰에서 합의해 요구사항 명세에 반영했습니다.
01

상황과 문제

기존 업무여러 경로로 오던 거래처 자료

  • 거래처 자료는 이메일·우편·카카오톡으로 내부 실무자에게 전달됐습니다. 실무자가 파일을 취합하고 엑셀로 정리해 입력하는 과정에서 자료 중복·누락과 잘못 전달된 자료를 확인해야 했습니다.
  • 직접 선택하는 화면은 선택지를 미리 제한할 수 있지만, 외부 자료는 들어온 뒤에야 확인할 수 있습니다.
02

해결

자료 전달 경로를 포털로 모아 거래처가 직접 올리도록 하고, 실무자는 취합·입력 대신 대조·보정·확정을 맡도록 역할을 나눠 설계했습니다.

03

결과

명세 반영

입력 경로별 검증 방식을 고객사 리뷰에서 합의했습니다.

  • 요구사항 명세경로별 검증 방식 반영. 직접 입력은 예방, 외부 자료는 들어온 뒤 대조
  • 역할 분리 설계거래처는 포털에서 업로드·확인, 실무자는 대조·보정·확정

출시 후 사용 효과를 측정한 사례는 아닙니다.

용어 풀이

EDI
거래처와 자료를 정해진 전자 형식으로 주고받는 방식(전자문서교환)
포털
거래처가 직접 들어와 자료를 올리고 확인하는 협력사용 화면
허용 품목
거래처별로 계약돼 고를 수 있는 품목
마스터
마스터데이터. 거래처·제품처럼 여러 업무가 함께 기준으로 쓰는 기본 정보
OCR
이미지 속 글자를 읽어 텍스트로 바꾸는 기술(광학 문자 인식)
크로스체크
